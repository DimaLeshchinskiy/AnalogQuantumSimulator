# AnalogSimulator construction

`config/parameters.scad` is the only place for shared dimensions. `core/`
contains reusable geometry and M3 T-slot mounting; `parts/` contains printable
part modules without top-level geometry.

## Global OpenSCAD libraries

- BOSL2 v2.0.752
- OpenSCAD_AluminumExtrusionProfile_Library at commit
  `577d78f11afdb139fba976a70d6749abe9f0308f`

The profile is generated by the latter library as a 40x20 mm V-slot, 500 mm
long, at X=0..40, Y=0..500, Z=0..20.

Use `assemblies/full.scad` as the workbench for the complete simulator. It
shows M3 socket-head bolts, washers and sliding T-nuts in their physical order:
bolt → washer → plastic mounting foot → profile → T-nut.

Export printable parts with:

```powershell
.\scripts\build-stl.ps1
```

Only files under `print/` are STL entry points. Assembly files are visual
checks and intentionally include non-printable optics and metal hardware.
